Devices

Select a model at the top. The connection status appears below the model selector. Interfaces on the same USB device are grouped. Connecting or disconnecting updates the list.

Lighting

Select the USB device using its checkbox. roccat checks OpenRGB at startup and when switching devices. If the SDK server is unreachable at startup, a prompt appears. After starting OpenRGB, select “Check OpenRGB” to retry. Choose a mode and set any available LED areas. If the mode supports multiple colors, “Color for all areas” copies one color to each area. Brightness and speed only appear if the SDK reports support. Magma has up to five areas and Kone Pro has up to two. Verify the effect on the physical device.

“Apply to device” sends the selected settings when clicked. Some modes may persist in device memory. Local profiles are separate. Starting the app leaves device settings alone, and no factory reset is offered.

Profiles

In the Profiles menu, “Save locally” stores your draft as a user-owned JSON file. “Load profile” selects an existing profile for the chosen model. Settings are staged when compatible SDK capabilities are available. “Duplicate” makes a separately named copy. “Rename” moves a profile to a new name. Existing names are protected.

Use the same menu to import or export JSON profiles. Import checks the format, backend and model. These file operations leave the USB device alone.

Lighting timeout

Open File → Settings → Lighting. For each device, choose “Always on” or “Turn off after inactivity”. With a timeout, enter 1 to 240 minutes and click “Save”. The suggested duration is 10 minutes. “Cancel” discards changes made since the last save.

Any mouse or keyboard activity in the same Cinnamon session resets both timers. Separate timeout values let the keyboard turn off before the mouse. The next input restores the previously active Direct profile with its colors and available settings. “Always on” disables the inactivity timeout. A manually applied black profile stays dark.

Apply a Direct profile first. The user service temporarily sets Direct colors to black. Restoring other modes can write to the device's permanent storage, so the timeout reports those modes as unsupported. Saved individual profiles are preserved. Timing requires a suitable Cinnamon session. The application explains when session idle time is unavailable.

After installing the package, run roccat-lichtdienst once as the desktop user. The command backs up the old profile startup unit and takes over its service name. At login, the service applies the last profile applied for each model. If there is no active assignment yet, the service uses the existing pc-tastatur.json and pc-maus.json files. “Load profile” loads a draft. “Apply to device” updates the active assignment.

Closing the window leaves the user service running. systemctl --user stop roccat-profil-start.service stops it for this session and attempts to restore lighting if the service switched it off. systemctl --user start roccat-profil-start.service starts it again. Startup profiles are applied after user login.

Local OpenRGB server

  1. In the roccat window, select a device, edit its profile and click “Apply to device”.
  2. The Python client sends the request to the OpenRGB SDK at 127.0.0.1:6742 over TCP.
  3. The roccat-openrgb.service system service controls the LEDs over USB/HID. It runs under the roccat-openrgb service account and stores its configuration in /var/lib/roccat-openrgb. The packaged udev rules grant access to the HID interfaces for 1e7d:3124 and 1e7d:2c88.
  4. The roccat-profil-start.service user service uses the same local connection for startup profiles and inactivity timing.

OpenRGB runs on the PC with the attached devices. The local address is sufficient. There is no need for router port forwarding or an OMV server. The application runs with normal user permissions.

USB detection and RGB controller matching are separate steps. A detected USB device is controllable only if OpenRGB reports a controller with the matching name, type and HID path. The user service retries a missing SDK or controller with increasing delays. After USB disconnection or suspend, it checks the device match again. If OpenRGB fails to detect the reconnected device, check the USB connection and OpenRGB device detection.

Check the system service with systemctl status roccat-openrgb.service and the startup and timing log with journalctl --user -u roccat-profil-start.service. SDK confirmation reflects the server's state. Verify the physical LED output on the device. Close competing RGB applications. keyd is a separate input remapper and is unnecessary for lighting.

Keyboard

Keyboard remapping and custom shortcuts were deliberately left out of roccat. Linux Mint Cinnamon already provides these controls under System Settings → Keyboard → Layouts and Shortcuts. roccat focuses on lighting.

Menus

Change the language under File → Settings. It takes effect immediately. File → Quit or Q closes the app. Help contains this guide (F1), About with Info and Credits, and the log file. A fresh log starts every time the application launches. It displays entries in the current language and records status and errors without keystrokes or profile content.

Use the separate “Version check” section to choose a daily, weekly or monthly check. roccat compares its installed version with the latest public release in the matching GitHub repository under Lehner-007. An overdue check runs when roccat starts. New releases are announced in the main window.
